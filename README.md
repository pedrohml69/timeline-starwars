# timeline-starwars

## Squad 7 - Linha do Tempo da Guerra Intergalática

### Objetivo
Criar uma página interativa de linha do tempo com o tema de Star Wars.

### Público-alvo
Fãs de Star Wars ou pessoas interesadas em um resumo dos momentos mais importantes da franquia.

### Funcionalidades
- Linha do tempo listando episódios ate o epsódio VI
- Efeitos e animações referenciando a saga
- Painel para ver as animações separadamente (podendo desliga-las ou visualiza-las com mais ênfase)

### Tecnologias
- HTML
- CSS
- JavaScript
- Api starwars-api (Akabab) para imagens

### Commit inicial

### Versão final (main)
- Animação de explosão no epsódio V na estrela da morte e painel para controlar as animações podendo parar elas ou visualizar elas separadamente.
